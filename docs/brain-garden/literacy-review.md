# 无识字游戏修订（2026-11-07）

## 行为契约
引导者可帮助选择游戏、讲解开局和试玩；正式回合中，玩家只需观察图形、记忆、匹配、比较数量或方向，不需要识别汉字、颜色名称、阿拉伯数字或算式。不用语音、音效或颜色编码作为唯一的规则提示。文字仍可为引导者与辅助技术提供补充，隐藏文字或静音不能阻止完成游戏。

## 十款逐项审查与决定
| 稳定 ID | 原问题 | 修订后的玩法及回合提示 |
|---|---|---|
| tiles | 眼/手提示小，目标数靠文字 | 保留记忆位置；大眼睛→手指明确阶段，星星圆点表示要找的数量，回合圆点标进度 |
| sequence | 顺序完成进度和阶段需要看字 | 保留不同形状闪烁与重现；眼/手图示与逐个填充的进度点，不能仅以颜色区分按钮 |
| pattern | 问号和文字解释下一项 | 保留图形接龙，空缺用虚线插槽和朝向插槽的箭头；答案全为形状 |
| numbers | 必须读数字、理解数列 | 改名「点点规律」，以有序点阵表现数量递增/递减与变化的步长，选下一组点阵；最大 16 个点，无数字字符 |
| odd | 可直接观察操作，但无具体开局示范 | 保留找异形；演示九格中圈出的异形与手指，反馈有勾/重试和正确格 |
| stroop | 识字是任务本身，换按钮颜色不能修复 | 改名「缤纷找色」；匹配中央图形的填色、忽略形状。正确选项色同形异，干扰选项形同色异，高级增加颜色和形状干扰；规则固定，提供图解和可纠错试玩 |
| compare | 必须读数字，高级还有算式 | 保留「大小速判」但比较两组点的多少，恒定尺寸的点阵按钮，选数量多者；高级数量更多、差距更小 |
| schulte | 必须认数字、逐个理解「下一位」 | 改名「图案追踪」；上方持续显示当前目标图章，在打乱网格中点完全相同的图章，点对后目标自动变更；无需认识名称、数字或顺序符号 |
| math | 必须读数字、加减乘符号 | 改名「点点合合」；两/三堆物体向同一空碗合并，被移除的物体有叉线与空心残影，选剩余数量的点阵；不用算式字符 |
| flip | 每轮必须读「一样/相反」 | 固定绿色圆框+平行双箭头表示同向，紫色菱形框+对向双箭头表示反向。双箭头始终用固定上下方向做规则符号，避免泄露当前题目答案。每题只突出一个大规则徽章，双图例以小尺寸被动参考呈现，避免误以为需要选择规则；两种模式均有可纠错试玩 |

## 共同界面
- 图形演示是具体已解例题，展示刺激→手指点选→正确反馈。手指直接附着在正确选项上，不用与选项布局分离的绝对位置；不能只有装饰封面或「看一看、点一点」。减少动画时图解仍完整。点点合合在开局同时示范合并和划掉移除，避免到游戏中才首次引入新符号。
- 核心规则图示和当前目标在正式回合持续可见。对/错有勾、重试或正确位置，记忆顺序错误时展示正确形状顺序；所有错误示范均保持到玩家按前进图标，不自动跳过。追踪点错有叉号，顺序复现成功时所有进度点填满。切换后台会暂停反馈。
- 回合进度增加非文字圆点。暂停为暂停符号，继续为播放，重玩为环形箭头，下一项为前进，回首页为小房子，完成每日为奖杯。退出确认同时有返家与继续播放，玩家不必读文字作选择。
- 结果分数/百分比允许作为补充；星星与明确的行动图标足以续玩。
- 比较题持续显示满点容器与向上箭头表示「更多」；接龙的空位箭头、合并题的汇合/移除路径直接常驻棋盘，不重复添加抽象装饰。
- 每日游戏图卡启动它展示的那一款；已完成图卡进入自由练习，不改变今日完成数量。主按钮仍自动续接首个未完成项目。
- 原有主导航保留中文并使用图标。关键玩法的颜色/文字旧封面同步替换，避免误导引导者。

## 数据兼容
保留所有游戏 ID、旧历史、每日计划和档案。不删除旧成绩。实质改变机制的六款游戏标记玩法版本 2，旧成绩不参与新版本起始难度或个人最好；成长总活动仍保留旧记录，记录区提示旧玩法记录已保留。档案隔离与存储格式 1 向后兼容。

## 验证与成功标准
先增加失败的生成器/界面测试，覆盖无文字刺激、干扰项与正确项、点阵边界、玩法版本兼容。更新真实作答测试，从可见形状/点阵/规则符号推导答案，不读取中文提示或隐藏答案数据；额外隐藏辅助文字、关闭声音，完成全部十款游戏及每日续玩/暂停/返回。验证 360px、最高难度、键盘与 axe、离线刷新。自动测试不能证明所有儿童/老人已理解；仍需与目标人群进行引导者示范后的实际可用性验证。
