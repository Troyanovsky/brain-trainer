# 首发游戏设计

统一 6 回合（舒尔特方格 3 轮），每轮正确为 100 基础分，乘以该轮难度，速度奖励最高 50 分乘难度；错误为 0，不倒扣。准确率＝正确回合/总回合。每场分数可随难度增长，趋势使用准确率避免跨难度误比。初始级别根据最近五场准确率，≥85% 升级、<50% 降级，1–5 边界；两次连续正确后下一回合提升一级，错误后降低一级。记忆展示时间不计入速度奖励。

| ID / 名称 | 能力 | 机制与演示 | 难度变化 |
|---|---|---|---|
| tiles 记忆闪格 | 记忆力 | 网格亮起若干格后隐藏；点回所有位置。错误即结束该轮。演示亮格→隐藏→点击 | 3×3 到 5×5，2–6 个目标 |
| sequence 星光顺序 | 记忆力 | 四色带形状按钮依次闪亮；按相同顺序点按。每个形状可区分 | 序列长度 2–6，展示逐步加速 |
| pattern 图形接龙 | 逻辑力 | 重复的形状序列有一个空缺，选择下一形状 | 循环长度 2–5，非仅颜色判定 |
| numbers 点点规律 | 逻辑力 | 显示等差/递增差值的点阵数量，四选一补齐，无数字字符 | 1–16 个圆点，步长 1/2，增加递减和变化的步长 |
| odd 火眼金睛 | 专注力 | 找出网格中唯一与其他不同的形状 | 3×3 到 5×5，从明显到细微的旋转差 |
| stroop 缤纷找色 | 专注力 | 匹配目标填色、忽略形状；正确项色同形异，干扰项形同色异 | 增加至 5–6 色，图解及可纠错试玩 |
| compare 大小速判 | 反应力 | 比较两堆圆点，选择更多的一堆，不需要数字/算式；无平局 | 数量增加、两堆差值缩小 |
| schulte 图案追踪 | 反应力 | 上方显示目标图章，点网格中完全相同的图案；点对后目标更换，错误不推进 | 2×2 到 4×4，3 轮；按错误点击计算轮准确与分数 |
| math 点点合合 | 灵活力 | 几堆圆点向同一空碗合并，划掉的圆点移除，选择剩余数量的点阵 | 两堆合并→增加数量→移除物体→三堆合并→三堆合并并移除 |
| flip 反向指令 | 灵活力 | 绿色圆框平行双箭头=同向；紫色菱形对向双箭头=反向。图例持续可见，文字仅为补充 | 两方向到四方向，高级打乱按钮位置，最高级加入斜向共八方向 |

正式回合不依赖识字或数字识别；具体图示、试玩和界面约束见 [无识字审查](literacy-review.md)。所有选择题选项唯一且包含正确项，生成逻辑可独立测试。反向箭头以左右/上下互为相反；题目不能依赖英文单词。速度奖励使用实际作答时间，按钮锁定防止重复计分。没有题目倒计时强迫结束；短会话依靠固定回合限制。
