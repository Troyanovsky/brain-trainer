# UX 与信息架构

## 导航

桌面左侧固定品牌栏：今日训练、游戏乐园、成长足迹；底部当前档案入口与设置。手机底部三栏导航，顶部头像开启档案。无深层导航、无登录屏。

## 今日训练

顶部日期、亲切问候和简短提示。主卡片是奶油黄色的「每天一点，脑力开花」，含原创 SVG 花园角色、四个能力小标签、今日完成计数、逐项勾选状态与唯一醒目的开始按钮。下方横排/竖排今日四项游戏，已完成为勾号；点图卡进入该款每日游戏，已完成图卡重玩算自由练习。侧边（手机下方）一周打卡花朵、真实连续天数和小贴士。底部展示可直接玩的精选游戏。

## 游戏

全屏专注界面：退出按钮、名称、难度、回合进度；先有具体已解例题的图形示范与一句话辅助说明。
中央方向、送物路线和拼块空位必须先完成可纠错、不计分试玩，再进入正式回合。原有缤纷找色和
反向指令保留可选试玩。题目中心与大块答案/网格，下方反馈。

正式回合的规则、目标、阶段、进度与反馈均有非文字表达。中央方向把目标锚定在中心，四周箭头
只作干扰；送物路线持续显示全盘、行走者、包裹槽和出口；拼块空位持续显示目标、预览及旋转/翻面
控件。方向规则用配色、框形与双箭头冗余编码；数量题使用点阵，追踪题使用目标图章。

每次答案锁定；标准游戏答对后短暂反馈自动进入下一回合，答错则保留图形纠错示范，等玩家按
前进图标再继续。记忆游戏先展示后隐藏，并防止展示阶段作答。送物路线和拼块空位完成或答错后都
由玩家确认下一步；路线可撤销/重开，拼块旋转/翻面不扣分。完成页用大分数、星星、正确率和个人
最好强调收获；送物路线与拼块空位的结算时间只是时长信息，不进入得分。今日场显示「下一项训练」
或「完成今日训练」，自由场显示「再玩一次」及返回。全部关键动作伴随播放、重玩、前进、返家、
奖杯等图标，文字可以隐藏而仍可继续。

## 成长

总练习次数、连续天数与已获徽章。七日活动用花朵与日期，14 天准确率折线配可访问文字，能力覆盖用五条彩色进度条；各游戏次数、最好成绩列表。成就：第一颗种子（1 场）、小小探索家（5 款）、全能园丁（10 款）、今日盛开（完成一天）、坚持的力量（3 天连续）、百发百中（全对一场）。

## 档案与设置

对话框展示现有档案与选中标记，可新增；单独编辑名称、头像；删除提供「取消/确认删除」。
每个档案保存音效开关与舒缓动画开关。删除前说明会清除整个本地旧版与恢复副本，以阻止已删除档案
残留在旧副本中；这些副本也可能包含其他档案的旧备份，因此会整份清除。当前规范记录中的其他档案
保留，已下载到应用外的文件需自行清理。

音效仅在用户手势后用本地 Web Audio 合成，不依赖资源下载。存储警告持久可见；受保护原始数据
可下载或清除一份已保存的快照。下载文件不是可导入的便携备份。浏览器没有 Web Locks 时仍可
临时练习，但界面明确提示不会保存。

## 无障碍

中文可访问名称，装饰 SVG 隐藏。形状/文字与颜色一起传递信息。对话框 Escape、Tab 循环、
关闭后焦点回到入口。成绩为 polite live region，题目清晰可定位。顺序点按代替拖拽；
不要求精确划动。页面失焦暂停可交互计时和反馈（记忆展示可重新演示），用户回来明确继续，
避免切后台惩罚。三款新游戏在 360px 与 768px 的交互目标实测至少 44px，且无横向溢出。
练习是娱乐活动，低分用鼓励语言，不构成认知或医学评估。
