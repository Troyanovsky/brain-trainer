### 当时发现并处理的问题

1. **SVG 花朵超出插画边界**：嵌套 SVG 继承了父画布尺寸，导致较小视口裁切。先用插画画布
   边界回归测试复现，再为花朵明确设置内部尺寸。
2. **生产离线脚本语法错误**：资源清单替换只替换了注释，残留空数组。新增隔离临时目录的
   构建/安装测试复现，修正完整占位符替换。断网测试还复现了静态服务器 `Vary: Origin`
   导致预缓存无法命中 CORS 模块请求的问题；只对当前版本静态资源忽略 Vary，并验证完全断网
   重载和游玩。临时目录在 finally 中清理。
3. **辅助文字与计分标签对比度偏低**：用 axe WCAG AA 检查复现，统一加深文字、调整能力颜色
   及选中标签背景，并扩大较小字号。动态弹窗扫描使用系统减少动态效果模式。
4. **损坏原始存储可能被新档案覆盖**：新增失败回归测试；保存前保留恢复副本，副本写入失败时
   拒绝覆盖原始数据。
5. **两款游戏高级别变化不足**：补强颜色迷踪的干扰比例与 5–6 色辨认；反向指令在高级打乱
   按钮，最高级加入八方向。
6. **测试自身问题**：曾并行启动两套 Playwright，测试产物目录发生冲突，最终统一串行运行。
