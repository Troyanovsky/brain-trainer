# PRD：脑力花园

## Outcome

面向使用简体中文、希望轻松养成每日练脑习惯的人群。打开即看到今日四项训练，一键开始，每项约 1 分钟；用图形操作和积极反馈降低阅读负担。应用仅提供娱乐与练习，不声称诊断或改善疾病。

## Scope

当前提供 13 款独立游戏、每日推荐、自由练习、成长记录、成就、本地多档案与离线使用。
无登录、服务器、排行榜、订阅或外部 AI。采用 React、TypeScript、Vite。

## Scenarios and acceptance criteria

- AC-1 今日训练：首次打开自动创建「小花」档案；首页显示四款覆盖四种不同能力的训练、总预计时长、0/4 进度。点击主要按钮直接进入首款游戏的图示演示。
- AC-2 推荐：由本地日期、档案、历史确定，当前日期的计划一旦生成保持不变。四项覆盖
  四种不同能力，考虑近期覆盖、历史准确率、近七日频率和昨日游戏，并用稳定哈希打破平局。
  `route` 与 `fit` 同属逻辑力，因此不会同时进入同一份计划；保存过的旧计划不重抽。
- AC-3 连续训练：每项完成显示真实分数、准确率、个人最好和鼓励。继续进入下一项，四项全部完成显示庆祝与完成状态。刷新后保留计划与已完成项目；自由练习不误计入今日计划。
- AC-4 游戏：13 款游戏均有演示、开始、退出、有限回合、正确答案或合法完成判定、
  即时反馈和真实结算。难度 1–5 依据当前规则的近期表现调整；同一场也随连续正确逐步增加挑战。
  中途退出不计作完成。正式回合不要求识别汉字、色名、数字或算式；变化的规则与目标、反馈、
  暂停/继续/退出/续玩均须有可用的非文字表达，隐藏辅助文字并静音仍可完成。引导者可以在
  开始前讲解规则和试玩；中央方向、送物路线、拼块空位必须完成各自可纠错的不计分试玩后才能开赛。
- AC-5 游戏库：按能力筛选，点击任何游戏独立游玩。展示图形封面、名称、能力、时长和个人最好；不能以静态卡片代替游戏。
- AC-6 成长：展示真实近七天活动、近 14 天趋势、五种能力覆盖、各游戏次数与最好成绩、连续天数和成就。无记录时诚实显示空状态，不生成假数据；图形有文字说明。
- AC-7 档案：创建、改名、换头像、切换、删除；名称 1–12 字，允许同名但 ID 不同。切换后训练、历史、设置、成就隔离。删除需明确确认，不能删除最后一个档案。退出在玩游戏后才能切换。
- AC-8 持久化：刷新与重启后数据保留；损坏数据和存储失败显示可理解提示，不能崩溃或假报
  保存成功。当前使用 `brain-garden-store` 受保护版本化外壳，旧 `brain-garden-v1` 只在首次
  严格校验后导入。多标签页写入经 Web Locks 串行化；失败关闭未知、损坏或未来数据。
  无 Web Locks 时可临时游玩但不持久化。跨标签页变更同步并中止过期游戏。
- AC-9 易用性：所有产品 UI 为自然简体中文；主要通用控件至少 48px，三款新游戏棋盘的
  交互目标至少 44px；360px 手机无横向滚动，平板与桌面布局合理。键盘可操作、清晰焦点、
  对话框焦点管理、非纯颜色反馈、尊重减少动态效果。
- AC-10 离线：生产构建在首次在线访问并完成缓存后，可离线打开与玩全部游戏；不依赖网络字体、图片或远程接口。

## Success criteria

首次访问到开始游戏不超过两次点击；今日训练全流程无需自行选游戏；所有进度均来自完成记录，档案互不影响。

## Assumptions

同一浏览器的 localStorage 为设备数据边界。清理浏览器数据会清空记录；不提供跨设备同步。
原始数据下载只是故障排查材料，不是便携恢复功能。日期使用设备本地日历日，跨午夜活动算作
完成时所在日；每日训练归属于发起日。固定四项，覆盖五种能力中的四种，以轮换确保覆盖。
